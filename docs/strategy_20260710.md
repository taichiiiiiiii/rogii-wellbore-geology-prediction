## 1. 確定した世界観（エビデンス付き）

### 1.1 テスト構造
- 隠しテスト = **約200 well**（公式Data記載）。可視3 wellはtrain複製のダミーで採点時に置換（公式）。
- **Public LB ≈ 26% ≈ 50 well / Private ≈ 150 well**（独立4系統のフォーラム合意。公式ページに%明記は無し）。
- Privateから外れ値well 1件をホストが採点除外済み（STAFF発言、一次情報）。

### 1.2 Public LBは「弱い計測器」
- per-well誤差は重い裾（上位10% wellがSSEの~50%）→ **n≈50のpooled RMSEは±0.4級のchurnが常態**。
  - byte-identicalコードのreseedだけでLB幅0.15〜0.49が複数系統で実証済み。
  - 当方ブートストラップ: 分布シフト無しでも50-well抽出で「blendが正味害」に反転する確率29%。
  - connortynan v4はLOO改善→LB悪化を経験し「n≈50のchurn、シフトではない」と自己結論（sub-v4と同型）。
  - 3位Tucker「public LB順位は無意味。CVを下げてshake-upを祈れ」「gap>3ftで初めて心配しろ」。
- **含意: LB差 <0.5ft で方針を変えない。判断は well-GroupKFold pooled CV で行い、LBは較正点としてのみ使う。**
- sub-v4 LB 9.456 の再解釈: 「blendは転移しない」と断定したのは**過剰反応の可能性が高い**（churnで説明可能な幅）。ただし+0.43は churn分布の1.6%タイルなので、候補の転移劣化が上乗せされている可能性は残る → **診断probe（ref 54509814、採点中）が判別する**。

### 1.3 分布シフト仮説は主要因ではない

- 可視3 wellのメタ特性も中庸（ただしtrain複製なので弱い証拠）。

## 2. 方針（固定する判断）

### 2.1 基本路線: 「すべてを特徴量としてstackに注入する」
- 出力blend（sub-v4/v5型）は**凍結**（probeが「候補転移OK」を示しても、blendの利得はstackへの特徴注入で同等以上に回収できることをR7が実証: blend −0.06 に対し注入 −0.25）。
- 新しい候補・情報源はすべて `*_d`（pf_blend基準デルタ）特徴としてstack v2.xに追加し、well-GroupKFold pooled OOFで採否判定（ゲート: 前ベスト−0.10）。
- **これは転移実証済みのアーキテクチャを太らせる戦略**であり、churnノイズに賭けない。

### 2.2 提出規律
- 提出は「CVで≥0.1改善が確定したモデル」のみ。public LBの±0.4は想定内としてLBに一喜一憂しない（較正点の蓄積として扱う）。
- 提出ごとに `sub-vN` タグ・ledger記録・masterは**LBベスト**でなく**CV+転移信頼性ベスト**に更新。
- 最終週（7/29-8/5）: robust（CVベスト・保守）+ aggressive（分散大・上振れ狙い）の2枠で締める。

### 2.3 現実的な目標設定
- CV 8.98 → 銀圏7.17には**あと−1.8ft**必要。金圏6.30は−2.7ft。
- Tuckerの「単一モデルCV 5.4」が存在証明: ベースモデルにまだ−3.5ft級のheadroomがある（手法は非公開）。**銀圏は特徴注入の積み上げ+モデル多様化で現実的、金圏はNN級の跳躍が必要**。
